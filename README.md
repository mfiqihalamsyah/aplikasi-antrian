# 🚗 Web-Based Queue Management System

A web-based queue management system built using PHP and MySQL, designed to simulate real-world queue handling in service environments.
This application helps organizations manage visitor queues efficiently through ticket generation and real-time queue calling.

---

## 🚀 Features

* Generate queue numbers for visitors
* Queue calling system for staff
* Real-time queue tracking
* Simple and user-friendly interface
* Sound notification for queue calling

---

## 🛠 Tech Stack

* PHP (Native)
* MySQL / MariaDB
* Bootstrap 5
* JavaScript

---

## 📂 System Overview

This system consists of two main interfaces:

### 1. Queue Registration (Visitor)

* Users take a queue number
* Option to print or display number

### 2. Queue Calling (Admin/Staff)

* Staff calls next queue
* Displays current and upcoming queue
* Supports voice notification

---

## ▶️ How to Run

1. Clone this repository
2. Import database from `/database` folder
3. Configure database connection in `/config`
4. Run using local server (XAMPP / Laragon)
5. Access via:

```
http://localhost/queue-management-system
```
